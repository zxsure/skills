# Interactive HTML — Acceptance Criteria & Visual-First Rubric

Every `.html` micro-application generated by the `interactive-html` skill is evaluated against **5 Hard Gates (Zero-Tolerance Blockers)** and a **100-Point Visual-First Craft Rubric**.

To pass acceptance, a generated `.html` artifact **must**:
1. Pass **all 5 Hard Gates (5/5)**, AND
2. Achieve a **Total Craft Score ≥ 85 / 100** when audited by `node skills/interactive-html/scripts/verify-html.mjs <file.html>`.

---

## Part 1: The 5 Hard Gates (Pass / Fail Blockers)

| Gate ID | Gate Name | Verification Rule | Failure Remediation |
| :--- | :--- | :--- | :--- |
| **HG-1** | **Self-Contained HTML5 Document** | Starts with `<!DOCTYPE html>`, contains inline `<style>` and `<script>`, and is saved inside `.interactive-html/<slug>.html` (never `/tmp`). | Inline all styles/scripts and write inside `.interactive-html/`. |
| **HG-2** | **Zero JS Syntax or Runtime Errors** | Every `<script>` block compiles cleanly via `new vm.Script()` with zero syntax errors. | Fix any syntax typos or undefined identifiers. |
| **HG-3** | **Sandbox & Offline Safety** | Zero `fetch(`, `XMLHttpRequest`, `WebSocket(`, Google Fonts, or unverified external `<script src="...">` calls. | Use deterministic in-browser simulation and native system fonts. |
| **HG-4** | **Visual-First & Anti-Clutter Gate** | 1. **No Cramped 3-Column Workspace Grids** (rejects `grid-template-columns: 1fr 1fr 1fr` style 3-pane dashboards).<br/>2. **Strict Text Diet**: Total words across all `<p>` paragraphs must be **`≤ 80 words`** so the visual animation teaches instead of prose.<br/>3. **Interactive Controls (`≥ 2` modalities)**: Includes tactile controls + direct canvas/SVG interaction. | Remove multi-column text boxes and long `<p>` paragraphs; center the page on one spacious animated stage. |
| **HG-5** | **Dynamic 60fps / Spring Visual Stage** | Contains an active `<canvas>` or `<svg>` stage animated via `requestAnimationFrame`, `<animateMotion>`, or spring physics (`F = -kx - cv`). | Animate objects gliding/snapping on `<canvas>` or `<svg>`. |

---

## Part 2: The 100-Point Visual-First Craft Rubric (Threshold: `≥ 85 / 100`)

### 1. Visual-First Simplicity & Text Diet (25 points)
- **+10 pts**: Zero cramped 3-column workspace layouts; uses a spacious single focal stage (or clean 2-part layout).
- **+10 pts**: Concise text diet (`≤ 60` words in `<p>` tags; `≤ 80` words max).
- **+5 pts**: Single-line live formula/query/status readout instead of walls of text.

### 2. Object-Permanence Motion & Retina HiDPI Craft (25 points)
- **+10 pts**: Continuous 60fps `requestAnimationFrame` physics loop, spring coordinate interpolation (`tx, ty`), or SVG `<animateMotion>`.
- **+8 pts**: Tactile spring easing (`cubic-bezier(0.34, 1.56, 0.64, 1)` or Hooke's Law spring damping).
- **+7 pts**: Crisp Retina `window.devicePixelRatio` scaling on all `<canvas>` elements.

### 3. Direct Manipulation & Intuitive Controls (25 points)
- **+10 pts**: Direct click, hover, or drag interaction on the `<canvas>` or `<svg>` stage itself.
- **+8 pts**: Tactile mode pills, sliders, or keyboard shortcuts that immediately re-choreograph the stage.
- **+7 pts**: Real in-browser domain calculation driving object positions/states.

### 4. Visual Aesthetic & Adaptive Theme (15 points)
- **+5 pts**: Cohesive CSS Custom Properties (`--`) palette.
- **+5 pts**: 1-click Dark / Light theme toggle (`data-theme`).
- **+5 pts**: Responsive layout that fits cleanly inside side preview panels.

### 5. Instant 3-Second Comprehension (10 points)
- **+5 pts**: Clear title and 1-sentence intuition hook.
- **+5 pts**: Color-coded visual states (e.g., green match, pink NULL/drop, cyan active).
